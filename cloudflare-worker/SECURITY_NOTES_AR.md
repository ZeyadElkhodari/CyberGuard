# ملاحظات الأمان

- مفاتيح Google Safe Browsing وURLhaus وVirusTotal محفوظة كـ Cloudflare Worker Secrets فقط.
- تطبيق Android يتصل بالـ Worker ولا يحتوي على مفاتيح المزودين.
- يتم قبول روابط HTTP/HTTPS العامة فقط، مع رفض localhost وعناوين IPv4 الخاصة الشائعة.
- تُستدعى خدمات استخبارات التهديدات الثلاث بالتوازي؛ فشل مزود لا يلغي نتائج الآخرين.
- عدم وجود تطابق في قاعدة بيانات لا يثبت أن الرابط آمن. يجب إبقاء الحالات غير الحاسمة ظاهرة للمستخدم.
- لا يرسل التطبيق أو Worker الروابط إلى PhishTank.
- لا تضع مفاتيح المزودين في ملفات المشروع أو تطبيق Android؛ أدرها من Cloudflare Worker Secrets.
